# Hypotheses and decisive tests

| ID | Hypothesis | Status | Falsifier / required observation |
| --- | --- | --- | --- |
| H0 | A fully isolated device gains net center-of-mass acceleration from only internal cyclical forces. | Incompatible with ordinary momentum conservation in the assumed isolated setting; no device claimed. | Boundary-explicit momentum accounting; rule out external coupling before accepting apparent thrust. |
| H1 | A prescribed Alcubierre shift automatically decouples encountered matter. | Not established; existing particle calculations counsel caution. | Solve matter trajectories and stress-energy, demonstrate small energy/momentum deposition across valid geometry and source. |
| H2 | Eulerian pressureless dust in a 1D steady, comoving prescribed shift obeys rho=rho0/(1-f). | DERIVED-CONDITIONAL, analytically and computationally checkable, fails for f=1 under finite steady density. | Insert in continuity equation; test finite-time, pressure and transverse-flow alternatives. |
| H3 | A specific candidate engine produces measurable force. | Not specified yet / UNKNOWN. | Pre-register power, momentum sink/source, predicted F(P), null controls, uncertainties and replication. |
| H4 | Reported UAP transmedium events imply warp propulsion. | SPECULATIVE, not established; not an input to equations. | Requires calibrated, independently verified kinematics and exclusion of sensor/interpretive alternatives. |

All claims require explicit scope, competing explanations and failure criteria. A failure is publishable project knowledge if reproducible.
