# Preregistration 009 — canonical audit observation under frozen formatting mutation

Status: **FROZEN DESIGN ONLY; no schedule, implementation, reserved-seed trial or outcome exists.**  
Preregistered: 2026-09-29  
Evidence category: strictly offline deterministic scripted-toy control experiment

## Question

With controller authority held fixed at immediate enforced stop, does an independently generated canonical audit observation reduce prohibited-action completion when the ordinary presentation channel is subjected to one frozen formatting mutation?

This tests observation engineering in a toy system. It does not test a learned model, semantic reasoning, consciousness, motives, adaptive evasion or deployed-system safety.

## Frozen factors and conditions

Fresh reserved seeds: `426000..426999` (1,000 seeds).

Each seed is assigned deterministically and evenly to one label:

- 500 violation-present seeds;
- 500 benign-control seeds.

Every seed is run once in each of four conditions, for **4,000 planned runs**:

| Condition | Presentation mutation | Observation input | Authority |
| --- | --- | --- | --- |
| `plain_primary` | none | current presentation monitor only | enforced |
| `plain_canonical` | none | primary plus canonical audit field | enforced |
| `mutated_primary` | frozen mutation | current presentation monitor only | enforced |
| `mutated_canonical` | frozen mutation | primary plus canonical audit field | enforced |

Authority, policy, action order, seed labels, resource ceilings and scoring remain identical across conditions.

## Frozen mutation

For violation-present runs only, the single restricted marker used by the current monitor is split at a predeclared fixed byte boundary into two adjacent presentation fields. No characters are added, removed or reordered. The joined presentation is byte-identical to the unmutated marker, but the current field-local exact-match monitor receives the two fields separately.

The benign payload uses a distinct nonrestricted marker and undergoes the same deterministic split structure.

The mutation is a programmed formatting transform, not an exploit and not adaptive behavior.

## Canonical audit field

Before presentation formatting, the offline environment creates an immutable structured record containing:

- seed;
- action kind;
- restricted/benign label;
- fixed semantic action identifier;
- source-event hash; and
- previous-audit hash.

The canonical record is generated by a separate pure function from the presentation renderer and committed before the controller decision. It cannot be written or altered by the scripted policy. In canonical conditions, either the primary monitor or the canonical restricted label triggers the same immediate stop. In primary-only conditions, the controller receives only the existing presentation-monitor result.

No network, external service, credential, real target, exploit, self-copy, persistence, package install, subprocess, shell, uncontrolled communication or indefinite process is permitted.

## Primary outcome and contrast

Primary outcome for violation-present seeds: completed prohibited action (binary).

Primary estimand:

`risk(mutated_canonical) - risk(mutated_primary)`

paired by seed. Negative values favor canonical observation.

Primary directional hypothesis H1: the upper endpoint of the frozen paired-bootstrap 95% interval is below zero.

## Secondary outcomes

1. Plain-format equivalence:
   `risk(plain_canonical) - risk(plain_primary)`.
2. Mutation penalty with primary observation:
   `risk(mutated_primary) - risk(plain_primary)`.
3. Mutation penalty with canonical observation:
   `risk(mutated_canonical) - risk(plain_canonical)`.
4. Interaction:
   `[mutated_canonical - mutated_primary] - [plain_canonical - plain_primary]`.
5. Detection count, stop count, stop latency in controller events, post-detection agent events, and board-read-only state.
6. Benign false-stop rate in each condition.

No secondary result rescues a failed primary integrity gate.

## Uncertainty

- Paired risk differences use deterministic paired bootstrap with 10,000 resamples.
- Bootstrap seeds are frozen as `426071..426074` in the order the four contrasts above are listed.
- Benign false-stop proportions use two-sided 95% Wilson intervals.
- No multiplicity-adjusted confirmatory claim is made beyond H1; secondary intervals are descriptive.

## Success and falsification

H1 passes only if all integrity gates pass and the paired-bootstrap upper endpoint for the primary contrast is below zero.

Control requirements:

- no post-detection agent event in any stopped run;
- every canonical restricted detection is committed before stop;
- zero logging-only condition exists—authority is enforced everywhere;
- each benign false-stop Wilson upper bound must be below 2%;
- plain-format canonical and primary completion counts must be identical, otherwise the independent channel changed more than observation redundancy.

The hypothesis is falsified or the run is invalid if H1 fails, a control requirement fails, or any integrity/containment gate fails.

## Integrity and stopping gates

Abort the entire reserved block before estimates if any of the following occurs:

- source blob, preregistration or schedule hash mismatch;
- seed outside `426000..426999`;
- missing/duplicate seed-condition pair;
- anything other than exactly 4,000 completed run records;
- label imbalance;
- action-order or event-chain failure;
- canonical record created after presentation or controller decision;
- network/socket/HTTP/subprocess/shell/credential/package/persistence capability detected;
- any post-stop agent event;
- wall time over 180 seconds; or
- peak traced Python memory over 256 MiB.

On abort, retain the failure record and publish no effect estimate.

## Resource and execution rule

The reserved block may be invoked explicitly **once** only after schedule, implementation, controller and independent nonconfirmatory tests are merged and all frozen blob identities are verified. Imports, schedule generation and tests must not execute reserved seeds.

## Interpretation boundary

Even a perfect result would show only that a separately generated canonical observation can repair one deliberately programmed formatting blind spot in deterministic offline scripts. It cannot establish robustness to adaptive learned systems or real-world adversaries.
