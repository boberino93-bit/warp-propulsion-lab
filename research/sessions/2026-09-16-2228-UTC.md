## ONE bounded falsifiable advance
Turn the v0.3.15 reaction-mass baseline into a quantitative calibration gate. For a pressure-matched nozzle, predicted momentum thrust is `F0 = mdot*Ve_ref`. Infer `Ve_meas=F/mdot`. For independent force and mass-flow uncertainties, `sigma_Ve/Ve = sqrt((sigma_F/F)^2 + (sigma_mdot/mdot)^2)`. With gravimetric `mdot=Delta_m/T` from two independent mass readings, `sigma_mdot/mdot = sqrt(2(sigma_m/Delta_m)^2 + (sigma_T/T)^2)`.

Momentum closure uses `z=(F-mdot Ve_ref)/sqrt(sigma_F^2 + (Ve_ref sigma_mdot)^2 + (mdot sigma_Ve_ref)^2)`. The predeclared pass gate requires BOTH `|z| <= 3` and absolute fractional thrust bias `|F-F0|/F0 <= 5%`. The dual gate prevents a deliberately inflated uncertainty from making a gross bias pass, while the z gate rejects statistically significant smaller biases. These thresholds are an engineering calibration criterion, not a discovery threshold.

Reference protocol calculation: `Delta_m=0.600 g` over `60.0 s`, 1-sigma mass-reading uncertainty `1 mg` per endpoint, timing uncertainty `0.01 s`, measured `F=1.000 mN` with `10 microN` 1-sigma force uncertainty, and independent `Ve_ref=100 +/- 1 m/s`. This gives `mdot=1.000e-5 kg/s`, `sigma_mdot/mdot=0.2363%`, `Ve_meas=100.0 +/- 1.03 m/s`, `z=0`, PASS. This is a numerical protocol example only; no apparatus was measured.

## Boundary / controls / falsification
The balance boundary includes tank, valve, nozzle and structure; expelled mass crosses the boundary. Pressure thrust must be measured/modelled separately if exit pressure is not ambient matched. A valid calibration run additionally requires zero-flow sham, nozzle reversal, plume-impingement exclusion, cable/service-force characterization, thermal dummy, airflow/acoustic/vibration controls, independent `Ve_ref`, and blinded/repeated runs where practical. Failure of either predeclared gate blocks unconventional-candidate testing until the stand discrepancy is resolved.
