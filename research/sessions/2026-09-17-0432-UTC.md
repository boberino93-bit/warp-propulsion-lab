## ONE bounded advance
The v0.3.21 NEXT ONE TEST exposed a protocol-design problem before a more elaborate 1/f simulation was justified: the existing four-state schedule (`ON+`, `ON-`, `OFF`, `SHAM`) has no polarity on SHAM. It therefore cannot directly measure an artifact caused by the polarity command itself. Added a five-state balanced randomized schedule: `ON+`, `ON-`, `SHAM+`, `SHAM-`, `OFF`. `SHAM+/-` uses the same polarity command while the candidate is physically prevented from generating thrust.

Define the raw candidate estimator `F_raw=(mean(ON+)−mean(ON−))/2`, the sham estimator `F_sham=(mean(SHAM+)−mean(SHAM−))/2`, and corrected estimator `F_corr=F_raw−F_sham`. For a command-correlated artifact `b` that is +b/-b under polarity reversal, `F_raw=F_true+b` and `F_sham=b`, so ideally `F_corr=F_true`. This does not prove that every artifact cancels: ON and SHAM must be physically matched except for the thrust-producing degree of freedom, and uncertainty from both estimators must be carried forward.

## Synthetic stress result
Added `src/reversal_sham.py` and `tests/test_reversal_sham.py`. The model uses the actual randomized five-state schedule, stationary AR(1) time noise, a linear thermal drift across the run and a reversal-correlated artifact. Frozen illustrative gate remains 14.4194 µN (`sigma=5 µN`, systematic bound 10 µN, 16 repeats/state, z=5). With reversal artifact 15 µN, thermal span 10 µN and 20,000 fixed-seed trials, raw null false-positive rates were 25.115% (rho=0), 25.845% (0.5), 28.595% (0.9), 22.230% (0.99). The polarity-matched sham-corrected null false-positive rate was 0 observed in all four synthetic cases. With a true injected 20 µN force under the same artifact, corrected detection was 99.985%, 99.980%, 99.995% and 100% respectively. These are synthetic model outputs, not empirical instrument performance or proof of a true zero false-positive probability.

## Interpretation / falsification
The advance is not that sham subtraction guarantees validity; it is that a polarity-matched disabled sham is structurally capable of identifying the exact reversal artifact that defeated v0.3.21, whereas an unpolarized SHAM is not. Before hardware claims, require SHAM+/- to reproduce command current/voltage, wiring forces, magnetic fields, thermal timing and control electronics while independently disabling the candidate's intended momentum exchange. If that physical matching cannot be demonstrated, the subtraction is invalid. A candidate signal fails if `F_raw` is reproduced in `F_sham`, if `F_corr` is not stable to schedule/thermal covariates, or if corrected null false positives exceed the preregistered allowance.
