## ONE bounded advance
Added `src/empirical_null_gate.py`. It freezes a two-sided threshold from an independent synthetic null-calibration ensemble using a conservative nearest-rank empirical `(1-alpha)` quantile, then evaluates false positives and a 20 µN injected signal on separate holdout RNG streams. Calibration and evaluation samples are therefore not reused. Default alpha is 1%.

This is deliberately narrower than claiming a general permutation test: the current implementation is an independent empirical holdout-null gate generated by the existing long-memory-like/no-linear thermal/imperfect-sham simulator. It does not yet prove exchangeability, stationarity, or validity of arbitrary blocked permutations, and it is not real sham data.

## Falsification / decision rule
The empirical gate is useful only if independent holdout null false positives remain near the preregistered alpha across the mismatch/drift/correlation envelope while injected-signal detection remains adequate. If calibration and holdout artifact distributions differ, the gate can fail and must be rejected rather than retuned after seeing candidate results.
