## ONE bounded advance
The prior stationarity work used a point-estimate false-positive ceiling. This run adds a conservative binomial uncertainty gate: a simulated stationarity point passes only when the Wilson confidence-interval upper endpoint for false positives is <= the preregistered ceiling. This prevents a low Monte Carlo point estimate from passing merely because the sample is too small.

The default implementation uses z=1.959963984540054 (the conventional two-sided 95% normal critical value); callers must explicitly choose a one-sided z if preregistering a one-sided confidence rule. Analytic checks: 10 false positives / 1000 trials gives point FPR 1.0% and Wilson upper about 1.831%, so it passes a 2% ceiling; 20/1000 has point FPR 2% but an upper endpoint above 2% and fails. Zero observed false positives still has a nonzero upper endpoint.
